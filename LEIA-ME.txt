CORRETOR OSCAR - SITE ESTÁTICO (HTML/CSS/JS puro)
=================================================

ESTRUTURA
---------
Esta pasta contém o site pronto, sem framework. É só esta pasta que você
precisa para publicar.

index.html    -> a página do site (abertura, lista de imóveis, contato)
admin.html    -> o painel administrativo (cadastro, fotos, exclusão, publicação)
style.css     -> todas as cores, fontes e layouts
app.js        -> a lógica do site (lista, filtros, galeria)
admin.js      -> a lógica do painel (senha, cadastro, excluir, publicar)
data.js       -> os imóveis que aparecem para todo visitante
imagens/      -> as fotos publicadas (criado na primeira publicação)
*.jpg         -> as fotos de exemplo (hero.jpg é a foto de abertura)

COMO PUBLICAR
-------------
1. Tenha uma hospedagem (Hostinger, Locaweb, Netlify, Vercel, GitHub Pages...).
2. Envie TODO o CONTEÚDO desta pasta para a pasta pública da hospedagem
   (costuma chamar public_html, www ou dist).
3. O site abre em http://seusite.com.br  e o painel em
   http://seusite.com.br/admin.html

Na Vercel o projeto precisa ter a raiz do repositório como pasta do site
(Vercel → Project → Settings → Build & Development → Output Directory = .).

COMO ENTRAR NO PAINEL
----------------------
Abra admin.html e digite a senha: 123
- Para trocar a senha, edite a linha 1 do arquivo admin.js:
  const SENHA_PADRAO = '123';   ->   const SENHA_PADRAO = 'a-senha-nova';
- A senha não é guardada em lugar nenhum: nem no site, nem no navegador.
  Se o navegador preencher o campo sozinho, limpe e digite de novo.

COMO ADICIONAR IMÓVEIS
----------------------
1. Abra o painel, entre com a senha e preencha o formulário ao lado.
   A primeira foto é a capa. Clique em "Salvar imóvel".
2. O imóvel entra na lista do painel na hora (e aparece no site, no mesmo
   navegador).
3. Clique em "Publicar no site" para que TODOS os visitantes vejam.
   - CAMPO AUTOMÁTICO (com token do GitHub): na primeira vez o painel pede o
     repositório e um token (Settings → Developer settings → Personal access
     tokens → Tokens (classic) → marque "repo"). O painel envia o data.js e as
     fotos (pasta imagens/) para o GitHub e a Vercel publica em 1-2 minutos.
     Depois de configurado uma vez, todo imóvel salvo vai para o site sozinho.
   - SEM TOKEN (dois passos, dentro da mesma janela):
     1) "Abrir o data.js no GitHub" abre o editor do GitHub com o conteúdo já
        copiado: é só colar (Ctrl+V) e clicar em "Commit changes".
     2) "Baixar pacote com as fotos" gera um zip com o data.js e a pasta
        imagens/ para arrastar em "Add file → Upload files".
     A Vercel publica do mesmo jeito.

EXCLUIR UM IMÓVEL
-----------------
No painel, em cada imóvel, clique em "Excluir". Abre uma janela de
confirmação com a foto e o nome do imóvel. Depois de excluir aparece um
aviso com o botão "Desfazer" (vale por alguns segundos). O imóvel também
sai da próxima publicação do site.

OUTROS BOTÕES DO PAINEL
-----------------------
- "Marcar vendido" / "Reativar": tira ou devolve o imóvel da exposição do
  site (vendidos não aparecem para os visitantes).
- "Baixar backup (.json)" / "Restaurar backup": salva e recupera a lista.
- "Restaurar lista padrão": volta para os imóveis que já vinham no site.

OBSERVAÇÕES
-----------
- Não há banco de dados: o que todo mundo vê vem do arquivo data.js; o
  painel guarda uma cópia no navegador de quem cadastra.
- O número de WhatsApp em index.html (5500000000000) e os textos "15+ anos" e
  "500+ famílias" são provisórios. Troque pelos dados reais.
- Preços, endereços e medidas dos imóveis de exemplo são fictícios.
