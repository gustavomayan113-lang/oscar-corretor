CORRETOR OSCAR - SITE ESTÁTICO (HTML/CSS/JS puro)
=================================================

ENDEREÇOS
---------
Site (público) : https://oscar-corretor-psi.vercel.app
Painel         : https://oscar-corretor-psi.vercel.app/admin.html
Repositório    : https://github.com/gustavomayan113-lang/oscar-corretor
ATENÇÃO: o endereço antigo oscar-corretor.vercel.app foi apagado na Vercel e
não funciona mais. Use sempre o endereço com "-psi".

ESTRUTURA
---------
Esta pasta contém o site pronto, sem framework. É só esta pasta que você
precisa para publicar.

index.html    -> a página do site (abertura, lista de imóveis, contato)
admin.html    -> o painel administrativo (cadastro, fotos, exclusão, publicação)
style.css     -> todas as cores, fontes e layouts
app.js        -> a lógica do site (lista, filtros, galeria)
admin.js      -> a lógica do painel (senha, cadastro, excluir, publicar)
api/publish.js-> função do servidor que publica os imóveis sozinha (Vercel)
data.js       -> os imóveis que aparecem para todo visitante
imagens/      -> as fotos publicadas (criado na primeira publicação)
*.jpg         -> as fotos de exemplo (hero.jpg é a foto de abertura)

COMO FUNCIONA A PUBLICAÇÃO (automática)
---------------------------------------
O site publica sozinho. Nobody precisa mexer em token, repositório ou GitHub:
1. O dono preenche o formulário e clica em "Salvar imóvel".
2. O painel envia a lista e as fotos para a função api/publish.js, que grava
   tudo no repositório com um único commit.
3. A Vercel publica em 1-2 minutos e o anúncio aparece para todos.

Isso vale para cadastrar, editar, excluir, desfazer, marcar como vendido e
restaurar a lista padrão: tudo é publicado sozinho.

O botão "Publicar agora" (ao lado do status) republica a lista na hora, se
alguma alteração ficar pendente.

COMO PUBLICAR NA HOSPEDAGEM
---------------------------
1. Tenha uma hospedagem (Hostinger, Locaweb, Netlify, Vercel, GitHub Pages...).
2. Envie TODO o CONTEÚDO desta pasta para a pasta pública da hospedagem
   (costuma chamar public_html, www ou dist).
3. O site abre em http://seusite.com.br  e o painel em
   http://seusite.com.br/admin.html

Na Vercel o projeto precisa ter a raiz do repositório como pasta do site
(Vercel → Project → Settings → Build & Development → Output Directory = .).

COMO ENTRAR NO PAINEL
----------------------
A senha é validada pelo servidor (variável de ambiente ADMIN_PASS na Vercel),
por isso o painel só abre pelo site publicado. O dono entra uma vez e o
navegador lembra (é só preencher o formulário dali em diante).
- Sem internet, o painel abre com a senha local: 123.
- Para trocar a senha: Vercel → Project → Settings → Environment Variables →
  ADMIN_PASS (e reiniciar o deploy).

COMO ADICIONAR IMÓVEIS
----------------------
1. Abra o painel pelo site (https://oscar-corretor-psi.vercel.app/admin.html)
   e entre com a senha.
2. Preencha o formulário ao lado. A primeira foto é a capa.
3. Clique em "Salvar imóvel". Pronto: o imóvel já entra no site (1-2 min).
   Não há botão de publicar, token ou passo manual.

PUBLICAR NA MÃO (só em caso de emergência)
-------------------------------------------
No fim do painel há a seção "Publicação manual (uso técnico)", com:
- "Publicar com token": usa um token do GitHub guardado só no navegador.
- "Abrir o data.js no GitHub" e "Baixar pacote com as fotos": envia o
  data.js e a pasta imagens/ pelo próprio GitHub.
Use apenas se a publicação automática estiver fora do ar.

EXCLUIR UM IMÓVEL
-----------------
No painel, em cada imóvel, clique em "Excluir". Abre uma janela de
confirmação com a foto e o nome do imóvel. Depois de excluir aparece um
aviso com o botão "Desfazer" (vale por alguns segundos). A exclusão é
publicada sozinha: o imóvel some do site em 1-2 minutos.

OUTROS BOTÕES DO PAINEL
-----------------------
- "Marcar vendido" / "Reativar": tira ou devolve o imóvel da exposição do
  site (vendidos não aparecem para os visitantes).
- "Baixar backup (.json)" / "Restaurar backup": salva e recupera a lista.
- "Restaurar lista padrão": volta para os imóveis que já vinham no site.

OBSERVAÇÕES
-----------
- Não há banco de dados: o que todo mundo vê vem do arquivo data.js; o
  painel guarda uma cópia no navegador de quem cadastra.
- Ou seja: um imóvel só aparece para os visitantes DEPOIS de publicado.
  Antes disso ele só existe no navegador de quem cadastrou.
- A publicação automática depende da função api/publish.js e das variáveis de
  ambiente na Vercel (GITHUB_TOKEN, GITHUB_REPO, GITHUB_BRANCH, PUBLISH_KEY e
  ADMIN_PASS). Se a Vercel mudar de plano ou o token do GitHub for revogado,
  é só recriá-las e republicar.
- O número de WhatsApp em index.html (5500000000000) e os textos "15+ anos" e
  "500+ famílias" são provisórios. Troque pelos dados reais.
- Preços, endereços e medidas dos imóveis de exemplo são fictícios.
