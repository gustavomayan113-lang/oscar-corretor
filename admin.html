Publicação manual (uso técnico)

Só use se a publicação automática estiver fora do ar.

Excluir imóvel

O imóvel sai da lista na hora e da próxima publicação do site. Dá para desfazer logo em seguida.

Publicar no site

É só configurar uma vez. Depois de salvar um imóvel, ele vai para o site sozinho (a Vercel publica em 1–2 minutos).

Para criar o token: no GitHub, abra Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token, marque a caixa repo e copie o código que aparecer. Cole aqui embaixo. Ele fica salvo só neste navegador e só serve para escrever os imóveis neste repositório.

Sem token? Dá pra fazer do mesmo jeito, em 2 passos:
O passo 1 abre o editor do GitHub já com o conteúdo copiado: é só colar (Ctrl+V) e clicar em "Commit changes". O passo 2 baixa um zip com o data.js e a pasta imagens/ para você arrastar em "Add file → Upload files". Sem token, sem API, a Vercel publica assim mesmo.
